Three ideas explain how a model writes a reply

  1. A token is a piece of text. The model reads tokens.
  2. The context window holds all the tokens the model sees.
  3. The model picks the next token, one token at a time.
  4. The new tokens join into the reply.
[STEP 1] তিনটা idea আজকের পুরো session চালাবে। প্রথমটা token। model তোমার লেখা পড়ে না, সে পড়ে ছোট ছোট টুকরো। [STEP 2] দ্বিতীয়টা context window। model একবারে যতটুকু দেখতে পায়, ঠিক ততটুকুই। পরীক্ষার হলের desk-এর মতো, desk ছোট হলে সব খাতা রাখা যায় না। [STEP 3] তৃতীয়টা next token। model পুরো উত্তর একবারে লেখে না। সে একটা token বাছে, তারপর পরেরটা, তারপর আবার পরেরটা। [STEP 4] এই token-গুলো জোড়া লাগিয়েই তুমি reply পাও। আজ প্রতিটা idea আমরা terminal-এ নিজের চোখে দেখব।

A model predicts the next token

  1. The model reads the text so far: The cat sat on the.
  2. The model gives a score to each possible next token.
  3. Sampling picks one token from the scores. Here it picks mat.
  4. The model adds the token to the text and predicts again. It repeats.
[STEP 1] এবার আমরা model-এর ভেতরে উঁকি দিই। model আসলে একটাই কাজ করে। এ পর্যন্ত লেখা text দেখে সে পরের token অনুমান করে। ধরো text হলো "The cat sat on the"। [STEP 2] model প্রতিটা সম্ভাব্য token-কে একটা score দেয়। বারের দৈর্ঘ্য যত বড়, সম্ভাবনা তত বেশি। মনে রেখো, এই বার একটা illustration, মাপা সংখ্যা নয়। [STEP 3] তারপর sampling এই বার থেকে একটা token বেছে নেয়। এখানে সে "mat" বেছেছে। [STEP 4] সেই token text-এর সাথে জোড়া লাগে। model আবার পরের token অনুমান করে। এভাবে পুরো উত্তর একটা একটা করে token-এ তৈরি হয়। [ASK] model কি পুরো বাক্য একবারে ভাবে? Text becomes tokens before the model sees it

  1. You send text to the model.
  2. The tokenizer splits the text into tokens.
  3. Each token has a number. The number is the token ID.
  4. The model reads only the token IDs. It does not read letters.
[STEP 1] তুমি model-কে text পাঠাও, যেমন "Tokenizers split rare words"। কিন্তু model অক্ষর বা শব্দ হিসেবে পড়ে না। [STEP 2] আগে একটা tokenizer এই text-কে ছোট ছোট টুকরোয় ভাঙে। প্রতিটা টুকরোর নাম token। দেখো, একটা শব্দও দুই টুকরো হতে পারে। কারণ model-এর একটা নির্দিষ্ট শব্দভান্ডার আছে। যা ভান্ডারে নেই, সেটা ছোট টুকরোয় ভেঙে লেখা হয়। চেনা আর সহজ শব্দ প্রায়ই একটাই token হয়। [ASK] তোমার কী মনে হয়, একটা শব্দ কি সবসময় একটা token? [PAUSE 3s] না, সবসময় না। [STEP 3] প্রতিটা token-এর একটা নম্বর আছে। এর নাম token ID। অনেকটা লাইব্রেরির বইয়ের নম্বরের মতো। [STEP 4] model শুধু এই নম্বরগুলো দেখে। অক্ষর দেখে না। এই slide-টা একটা illustration। আসল ভাগ আর আসল ID প্রতিটা model-এ আলাদা। এক model-এর tokenizer দিয়ে আরেক model-এর token গোনা যায় না। তাই পরের slide-এ আমরা আসল token সংখ্যা গুনে দেখব। বাসায় worksheet-এ একই বাক্য বাংলায় লিখে গুনে দেখো, সংখ্যাটা কেমন আসে।

  1. Context: the model sees the task and all earlier results.

One loop uses all eight ideas

  1. The agent loop has four parts: context, plan, act and check.
  2. Context: tokens fill the context window. The prompt shapes it.
  3. Plan: effort sets how much rough work the model writes. Structured output gives our code a valid action.

  5. Check: the loop repeats or stops. The model can be wrong, so verify with a tool.
