One loop uses all eight ideas

  1. The agent loop has four parts: context, plan, act and check.
  2. Context: tokens fill the context window. The prompt shapes it.
  3. Plan: effort sets how much rough work the model writes. Structured output gives our code a valid action.
  4. Act: a tool call asks our code to do the work.
  5. Check: the loop repeats or stops. The model can be wrong, so verify with a tool.
[STEP 1] শুরুতে তুমি Hello লিখে ভেবেছিলে, box-এর ভেতরে কী ঘটে? এখন box খোলা। ভেতরে আছে token, context window আর একটা loop। এবার সব জোড়া লাগাই। এই চারটা ধাপ, context, plan, act আর check, মিলে হলো agent loop। আজ আমরা এটাই টুকরো টুকরো করে দেখলাম। ওপরের চিপগুলো হলো আজকের আটটা idea। [STEP 2] Context হলো model-এর পরীক্ষার desk। সেখানে token-গুলো জমে, context window-এর একটা সীমা আছে, আর prompt ঠিক করে দেয় desk-এ কী কী রাখা হবে। [STEP 3] Plan-এ model ভাবে। effort ঠিক করে সে কতক্ষণ ভাববে। আর structured output মানে সে JSON-এ বলে কী করতে চায়, যাতে আমাদের code সেটা পড়তে পারে। [STEP 4] Act হলো আমাদের code-এর কাজ। model নিজে কিছু চালায় না। tool call দিয়ে সে শুধু অনুরোধ করে। তাই code-এর ওপর আমাদের পুরো নিয়ন্ত্রণ থাকে। [STEP 5] Check-এ ঠিক হয় loop আবার ঘুরবে, নাকি থামবে। model ভুল বলতে পারে, এটাকেই বলে hallucination, তাই বাস্তব system-এ এই ধাপে আমরা tool দিয়ে উত্তর মিলিয়ে নিই। [ASK] আটটা idea-র মধ্যে কোনটা তোমার কাছে সবচেয়ে নতুন ছিল? [PAUSE 5s]

You write one agent at home

  1. The worksheet has eight tasks. Each topic has one task.
  2. Run one command. Write what you notice. Each command has a cost cap.
  3. In the last tasks, finish loop.starter.mjs and run your own agent.
  4. To learn agentic engineering basics and practices, read tahmid12khan.github.io/claude-basics.
[STEP 1] আজ যা দেখলে, বাসায় নিজে হাতে করবে। একটা worksheet আছে। আটটা task, প্রতিটা topic-এর জন্য একটা করে। প্রতিটা task-এর সঙ্গে লেখা আছে কী লক্ষ করতে হবে, মানে what to notice। [STEP 2] প্রতিটা task-এ একটা command চালাবে, result পড়বে, আর খাতায় লিখবে কী চোখে পড়ল। প্রতিটা command-এ খরচের একটা সীমা বসানো আছে, তাই ভয় পাওয়ার কিছু নেই। দরকার হলে এক command বারবার চালিয়ে দেখো, ফল একই হয় কি না। [STEP 3] শেষের task-গুলো সবচেয়ে মজার। তোমাদের হাতে থাকবে loop.starter.mjs। ওটা সম্পূর্ণ করলে তোমার নিজের agent চলবে। আজ আমি যেটা চালিয়ে দেখালাম, সেটাই তুমি নিজে লিখবে। আজ তুমি black box-এর ভেতরটা দেখেছ। বাসায় নিজের হাতে সেটা বানাও। আটকে গেলে আগে notes ফোল্ডারের চারটা ফাইল দিয়ে চেষ্টা করো। [STEP 4] agentic engineering-এর basics আর ভালো practice-গুলো শিখতে চাইলে tahmid12khan.github.io/claude-basics সাইটটা দেখো। link-টা এই slide-এর নিচে আছে। [ASK] কারো কোনো প্রশ্ন আছে?
