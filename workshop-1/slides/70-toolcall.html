A tool call is a request in JSON

  1. Our loop asks the model for JSON with action and args.
  2. Our code adds the tool result to the transcript as text.
  3. The native API returns a tool_use block. It has a name and an input.
  4. We answer with a tool_result block. It uses the same id.
  5. The idea is the same. loop.mjs uses --json-schema to imitate tool_use.
[STEP 1] আমাদের loop.mjs-এ model একটা JSON ফেরত দেয়। এতে দুটো জিনিস জরুরি: action আর args। action বলে কোন tool, args বলে সেই tool-এর input, যেমন path। এটা আমাদের নিজেদের বানানো format। thought নামে একটা বাড়তি field-ও আছে, সেটা আমরা শুধু দেখার জন্য রাখি। [STEP 2] আমাদের code tool চালায়, তারপর ফল একটা সাধারণ text হিসেবে transcript-এর শেষে জুড়ে দেয়। আগে Action লাইন, তারপর Result লাইন। [STEP 3] এবার আসল API-র দিকে তাকাও। সেখানে model একটা tool_use block পাঠায়। name হলো আমাদের action, input হলো আমাদের args। সাথে একটা id থাকে। [STEP 4] আমরা ফল পাঠাই tool_result block-এ, ওই একই id দিয়ে, যাতে model বুঝতে পারে এটা কোন অনুরোধের উত্তর। [STEP 5] দুটোর idea এক। আজ আমরা native API চালাচ্ছি না, কারণ তাতে API key লাগে। তাই loop.mjs-এ --json-schema দিয়ে model-কে বলেছি, এই আকারেই JSON দাও। এটা tool_use-এর নকল।
