Today we open the black box

  1. Type Hello in a chat window.
  2. Something inside the box reads your text.
  3. A reply comes back.
  4. Today we open the black box.

Three ideas explain how a model writes a reply

  1. A token is a piece of text. The model reads tokens.
  2. The context window holds all the tokens the model sees.
  3. The model picks the next token, one token at a time.
  4. The new tokens join into the reply.
[STEP 1] তিনটা idea আজকের পুরো session চালাবে। প্রথমটা token। model তোমার লেখা পড়ে না, সে পড়ে ছোট ছোট টুকরো। [STEP 2] দ্বিতীয়টা context window। model একবারে যতটুকু দেখতে পায়, ঠিক ততটুকুই। পরীক্ষার হলের desk-এর মতো, desk ছোট হলে সব খাতা রাখা যায় না। [STEP 3] তৃতীয়টা next token। model পুরো উত্তর একবারে লেখে না। সে একটা token বাছে, তারপর পরেরটা, তারপর আবার পরেরটা। [STEP 4] এই token-গুলো জোড়া লাগিয়েই তুমি reply পাও। আজ প্রতিটা idea আমরা terminal-এ নিজের চোখে দেখব।
