The context window is the model’s desk

  1. The model sees only what is on its desk.
  2. The desk always holds the system prompt and the tool list.
  3. Your messages and files go on the desk too.
  4. The desk has a size limit. When it is full, nothing more fits.
[STEP 1] এতক্ষণ দেখলাম token দিয়ে খরচ হয়। এবার প্রশ্ন, এই token-গুলো model কোথায় রাখে? ধরো তুমি পরীক্ষার হলে বসেছ। desk-এ যা আছে, শুধু সেটাই তুমি দেখতে পাও। model-এর বেলায়ও তাই। এই desk-এর নাম context window। [STEP 2] পরীক্ষা শুরুর আগেই desk-এ দুটো জিনিস রাখা থাকে। একটা system prompt, আরেকটা tools-এর তালিকা। এগুলো সবসময় থাকে। এই জায়গা তুমি ঠিক করো না, Claude Code আগেই রেখে দেয়। নিচের বারে দেখো, জায়গা খরচ হতে শুরু করেছে। [STEP 3] তারপর তোমার message আর model-এর উত্তর desk-এ জমে। তুমি কোনো file পড়তে দিলে সেই পুরো file-ও desk-এ উঠে আসে। তুমি যত বেশি লিখবে বা পড়াবে, desk তত ভরবে। বার ভরে যাচ্ছে। [STEP 4] কিন্তু desk-এর একটা মাপ আছে। ভরে গেলে আর কিছু ধরে না। একেই বলে context limit। [ASK] desk ভরে গেলে তুমি কী করবে? পুরোনো কাগজ ফেলে দেবে, নাকি summary লিখে রাখবে? [PAUSE 5s] summary-টাই আমরা compaction-এ দেখব। window-এর মাপ model ভেদে আলাদা। পরের demo-তে আমরা আসল মাপ দেখব।

The model has no memory between calls

  1. Call 1 sends your first message.
  2. Call 2 sends the full chat again, plus the new message.
  3. Call 3 sends everything again. The request grows with each call.
  4. The model keeps nothing. The app sends the full chat each time.
[STEP 1] এবার একটা মজার কথা শোনো। model-এর কোনো memory নেই। Call 1-এ তুমি লিখলে "Port is 8081"। model উত্তর দিল। তারপর সে সব ভুলে গেল। ভাবো এক রাঁধুনির কথা, যে প্রতিবার রান্না শেষ করে সব ভুলে যায়। তাকে প্রতিবার পুরো order slip আবার দিতে হয়। [STEP 2] Call 2-এ তুমি নতুন প্রশ্ন করলে। তখন তোমার app আগের পুরো chat আবার পাঠায়, সাথে নতুন message। দেখো, request-এর বক্সটা বড় হয়েছে। [STEP 3] Call 3-এও একই। সব কিছু আবার যায়। বক্স আরও বড়। ChatGPT তোমাকে মনে রাখে বলে মনে হয়। কারণ app প্রতিবার পুরো chat আবার পাঠায়। [STEP 4] এর দুটো ফল আছে। প্রথমত, model যা মনে রাখে বলে মনে হয়, তা আসলে তোমার পাঠানো text। দ্বিতীয়ত, প্রতি call-এ token বাড়ে, তাই খরচও বাড়ে। এ কারণেই context window ভরে যায়। [ASK] তাহলে chat খুব লম্বা হলে কী হবে? [PAUSE 5s] window ভরবে, খরচ বাড়বে। পরের demo-তে এটাই দেখব।
