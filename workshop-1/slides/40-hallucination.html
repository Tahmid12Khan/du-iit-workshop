A confident answer is not always a correct answer

  1. A viva asks a question. A prompt asks a question.
  2. The student does not know. The model only picks likely words.
  3. Both give a firm and fluent answer.
  4. A fluent answer can be wrong. Check the fact.
[STEP 1] ধরো তোমার viva হচ্ছে। Examiner একটা প্রশ্ন করেন। আমরা model-কে prompt দিয়ে প্রশ্ন করি। [STEP 2] ধরো ছাত্রটা উত্তর জানে না। model-ও জানে না, কারণ সে তথ্য খুঁজে দেখে না। সে শুধু সবচেয়ে সম্ভাব্য পরের শব্দগুলো বেছে নেয়। [STEP 3] দুজনেই খুব আত্মবিশ্বাসের সাথে গুছিয়ে উত্তর দেয়। গলা শুনে বোঝার কোনো উপায় নেই কে জানে আর কে জানে না। [STEP 4] সমস্যা হলো, গুছিয়ে বলা উত্তর মানেই ঠিক উত্তর না। ভুল তথ্যও সুন্দর ভাষায় আসে। এটাকেই বলে hallucination। তাই উত্তর যত সুন্দরই হোক, নিজে একবার মিলিয়ে নাও। [ASK] এমন কোনো ঘটনা কি হয়েছে, যখন AI খুব আত্মবিশ্বাসে ভুল বলেছে? The model gives an old version as a fact

  1. Ask the model for the latest version of express.
  2. The model answers 5.1.0. It shows no doubt.
  3. Ask npm for the real version.
  4. npm returns 5.3.0.
  5. The model gave an old version. Its knowledge stops at the training cutoff.
[STEP 1] এবার একটা আসল পরীক্ষা। আমি model-কে জিজ্ঞেস করছি, npm package express-এর সর্বশেষ version কত? শুধু সংখ্যাটা বলতে বলেছি। প্রশ্ন সোজা, কোনো ধাঁধা নেই। [STEP 2] [DEMO H1] [DO: H1 cast নিজে চলবে] Claude Code চালিয়েছি --tools "" দিয়ে, মানে model-এর হাতে কোনো tool নেই। উত্তর এল 5.1.0, একটুও দ্বিধা নেই। কখনও কখনও model নিজেই বলে, আমি live registry দেখতে পারি না। সেটা ভালো আচরণ। কিন্তু এই recording-এ সে সোজা 5.1.0 বলেছে। [PAUSE 3s] [STEP 3] এবার model-কে বিশ্বাস না করে আমরা npm-কে জিজ্ঞেস করি। [STEP 4] [DEMO H2] [DO: H2 cast নিজে চলবে] একই session-এ ! দিয়ে shell command চালাই: npm view express version। আমি যেদিন মেপেছি, মানে 2026-10-16, সেদিন npm বলছে 5.3.0। তুমি আজ চালালে নতুন version-ও দেখতে পারো। [STEP 5] তাহলে model-এর উত্তর পুরোনো। কেন? model শুধু training data পর্যন্ত জানে। এই training cutoff-এর পরে যা ঘটেছে, সে জানে না। আর সে নিজেও জানে না যে সে জানে না। তাই পুরোনো তথ্যও সে সত্যের মতো বলে, যেন পুরোনো খবরের কাগজ পড়ে আজকের খবর বলছে। [ASK] তোমরা কি কখনও পুরোনো library version নিয়ে AI-এর কথায় ঝামেলায় পড়েছ? [PAUSE 5s]

Let the model say I do not know

  1. Ask about a package. Tell the model it can say I do not know.
  2. The model says I do not know. It invents no options in this run.
  3. Ask npm if the package exists.
  4. npm returns E404. The package does not exist.
  5. Give the model a safe way out. One run is no proof. Check the fact with a tool.
[STEP 1] এবার আরেকটা প্রশ্ন। একটা package, নাম fastjson-validator-kit। আমি নামটা বানিয়েছি, এটা আসলে নেই। prompt-এ একটা বাক্য যোগ করেছি: না জানলে বলো, I don't know। [STEP 2] [DEMO H3] [DO: H3 cast নিজে চলবে] model বলছে I don't know। কোনো option বানিয়ে বলেনি। invented option শূন্য। সৎ কথা হলো, আজ এই model ভুল বানায়নি। আমরা বের হওয়ার রাস্তা ছাড়া তুলনা করিনি, তাই এই একটা run প্রমাণ করে না যে ওই বাক্যের জন্যই এমন হয়েছে। তবু বের হওয়ার রাস্তা দেওয়া ভালো অভ্যাস। [STEP 3] তবু আমরা model-এর কথায় থামি না। npm-কে জিজ্ঞেস করি package আছে কি না। [STEP 4] [DEMO H4] [DO: H4 cast নিজে চলবে] npm view। E404, মানে package নেই। [STEP 5] দুটো উত্তর মিলল। model বলল জানে না, npm বলল নেই। শিক্ষা: model-কে জানি না বলার সুযোগ দাও, তারপর tool দিয়ে মিলিয়ে নাও। এই দুই ধাপ তুমি নিজের agent loop-এ যোগ করতে পারো। [PAUSE 3s]

Check each fact with a tool

  1. The model makes a claim.
  2. Pick a tool that can prove the claim.
  3. Run the tool. Read the real result.
  4. If the result is different, reject the claim.
[STEP 1] model একটা দাবি করে। যেমন, express-এর সর্বশেষ version 5.1.0। বা, fastjson-validator-kit নামে একটা package আছে। [STEP 2] প্রতিটা দাবির জন্য এমন একটা tool বাছো, যে প্রমাণ দিতে পারে। version-এর জন্য npm view। কোডের জন্য test চালাও। API-র জন্য docs পড়ো। [STEP 3] tool চালাও, আসল ফল দেখো। npm বলল 5.3.0, আর E404। [STEP 4] ফল না মিললে দাবি বাতিল করো। agent loop-এর check ধাপে এই রকম যাচাই বসানো যায়। আজকের ছোট loop-এ check শুধু ঠিক করে, loop চলবে নাকি থামবে। বাসায় তুমি এখানে test বা npm view-এর মতো যাচাই যোগ করতে পারো।
